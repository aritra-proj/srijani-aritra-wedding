# 🌸 Srijani & Aritra — Subho Vivah (Royal Wedding Ceremony Invitation) 💍

An interactive, royal, and responsive wedding ceremony invitation web page created for the **Bride's side (Srijani's Family)** celebrating the auspicious **Subho Vivah** of **Srijani & Aritra** on **Saturday, December 12, 2026** in Kolkata.

---

## ✨ Key Features & Highlights

1. 👫 **Interactive 2-Avatar Gateway Unveiling Stage**:
   - Guests are greeted by two glowing character cards: **The Groom (Aritra)** on the left and **The Bride (Srijani)** on the right, linked by a sacred floral path and mandap altar.
   - **Click on Bride (Srijani)**: Srijani takes happy animated steps across the screen towards Aritra, leaving a trail of rose petals and hearts.
   - **Click on Groom (Aritra)**: Aritra happily walks across the screen towards Srijani.
   - When they meet, a garland union (Jaimala) celebration triggers with harp fanfare, floating hearts, and multi-colored confetti explosions!
   - Velvet silk curtains part smoothly to reveal the grand invitation page.
   - Fallback: Guests can also scroll down or tap the bottom hint to automatically trigger the union.

2. 👑 **Auspicious Bengali Wedding Ceremonies Timeline**:
   - **Gaye Holud (গায়ে হলুদ)** — Morning turmeric glow and blessings (10:30 AM)
   - **Bor Jatri & Bor Boron (বর বরণ ও আগমন)** — Evening welcome with Shankha & Ulu dhwani (7:00 PM)
   - **Saat Paak & Subho Drishti (সাতপাক ও শুভদৃষ্টি)** — The sacred 7 circles and garland exchange (7:45 PM)
   - **Sindoor Daan & Saptapadi (সিঁদুরদান ও সপ্তপদী)** — Vedic fire mantras and vermilion (8:30 PM)
   - **Royal Wedding Feast (শুভ প্রীতিভোজ)** — Lavish traditional banquet (8:00 PM onwards)

3. 📸 **Cherished Moments Polaroid Wall with Modal Lightbox**:
   - Features real couple photos from `images/together1.jpg` to `images/together5.jpg`.
   - Includes love heart reaction counter buttons and high-res lightbox preview on tap.

4. ⏳ **Live Countdown & Calendar Reminders**:
   - Dynamic days, hours, minutes, seconds countdown to Saturday, Dec 12, 2026, 7:00 PM IST.
   - **Add to Google Calendar** button (pre-filled with dates, location, and description).
   - **Download Apple / Outlook (.ics)** file download.

5. 💌 **Interactive Celebration Blessing Board & RSVP**:
   - Guests can write blessings, pick cute auspicious stickers, and RSVP.
   - Instant confetti explosions on posting!
   - Integrated live with Google Sheets via Web App API:
     `https://script.google.com/macros/s/AKfycbyykqh2KP9YaLuO9IlxzZL6u7fLi_Me720fm8uH8sspE1HTlqrFbJjSEjJFRTjSI2s/exec`
   - Real-time reading on page load & background submission with client device and IP logging.

6. 🎵 **Web Audio API Romantic Shehnai & Harp Synthesizer**:
   - Soft, pleasant pentatonic melody generated completely via Web Audio API (zero external MP3 downloads required).
   - Floating audio toggle button with dancing music wave indicator.

7. 🌸 **Falling Rose & Marigold Petal Physics**:
   - Realistic canvas physics with crimson rose, soft pink, and marigold golden petals.

8. 🚶‍♂️ **Scroll-Progress Walking Couple Tracker**:
   - At the bottom of the screen, Srijani and Aritra walk towards each other as guests scroll down and unite into `#SRIARI • Subho Vivah 💖` at the end!

## 🚀 How to Host on GitHub Pages (Step-by-Step)

### Option 1: Drag & Drop via GitHub Web
1. Go to [GitHub.com](https://github.com) and click **"New Repository"**.
2. Name it (e.g., `srijani-aritra-wedding` or `subho-vivah-invitation`).
3. Set visibility to **Public** and create repository.
4. Click **"Upload files"** and drag all files from this folder (`index.html`, `style.css`, `app.js`, `images/`, etc.).
5. Commit the files.
6. Go to **Settings** ➔ **Pages** ➔ under **Branch**, choose `main` / `root` and click **Save**.
7. Your page will be live at `https://<your-username>.github.io/<repo-name>/`.
